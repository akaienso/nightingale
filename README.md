# Nightingale

A Ukrainian ↔ American English translation web app. The in-app AI language guide
is **Olia** — she doesn't just translate words, she bridges culture, explains
nuance, and helps you sound natural in either language.

This repository is the full application source, intended here as a learning /
professional-development exercise.

---

## Tech stack

- **Next.js 14** (App Router) + **React 18** + **TypeScript**
- **Tailwind CSS** + shadcn/ui component library
- **Prisma** ORM with a **PostgreSQL** database
- **NextAuth** for authentication (email/password + optional Google sign-in)
- Hosted LLM API for the translation and chat features

## Project layout

```
nextjs_space/
├── app/                    # Next.js App Router: pages, layouts, API routes
│   ├── api/                # Server routes (translate, chat, account, history, ...)
│   ├── components/         # App feature components (panels, modes, header, ...)
│   ├── changelog/          # /changelog page
│   ├── site/               # marketing/landing content
│   └── layout.tsx          # root layout + metadata
├── components/ui/          # reusable shadcn/ui primitives
├── hooks/                  # custom React hooks
├── lib/                    # utilities: i18n, changelog, anthropic client, rate-limit
├── prisma/                 # schema.prisma (data model)
├── public/                 # static assets
├── types/                  # shared TypeScript types
├── package.json
└── .env.example            # copy to .env and fill in
```

A few good places to start reading:

- `lib/i18n.ts` — the full EN/UK translation dictionary and the `translate` helper.
- `app/api/translate/route.ts` — how Olia's system prompt is assembled (style,
  format, emoji and cultural-note logic).
- `app/components/two-panel-mode.tsx` — the main translate UI (source/target panes,
  quick controls, paste handling).
- `prisma/schema.prisma` — the data model (users, accounts, translation history,
  chat conversations).

## Getting started locally

### 1. Prerequisites

- Node.js 18+ and [Yarn](https://yarnpkg.com/)
- A PostgreSQL database (local install, Docker, or a hosted dev instance)

### 2. Install dependencies

```bash
yarn install
```

### 3. Configure environment

```bash
cp .env.example .env
```

Then edit `.env`. At minimum you need `DATABASE_URL`, `NEXTAUTH_SECRET`
(generate with `openssl rand -base64 32`), and `NEXTAUTH_URL=http://localhost:3000`.
The AI, Google sign-in, upload, and analytics keys are optional — see the comments
in `.env.example` for what each one unlocks.

### 4. Set up the database

```bash
yarn prisma generate      # generate the Prisma client
yarn prisma db push       # create the tables from schema.prisma
```

### 5. Run the dev server

```bash
yarn dev
```

Open http://localhost:3000.

## Notes

- The translation and chat API routes call a hosted model through
  `lib/anthropic.ts`. Without a valid AI key those specific responses won't
  generate, but the rest of the app (UI, auth, history, settings, i18n) runs fine
  for study.
- `.env` is intentionally **not** included in this archive — it holds secrets.
  Use `.env.example` as your template.
- `node_modules/` and build output (`.next/`, `.build/`) are not included; they are
  regenerated by `yarn install` and `yarn build`.
